# 개발 계획 — ENSAPIA Slack 비즈니스 메시지 AI 번역 워크벤치

상태: 작성 중 (다음: R2 확정과 개발 준비도 점검)

진행 방법: `$vibe:build`를 입력하면 첫 미완료 STORY부터 하나씩 개발합니다.

🎯 1차 목표: EPIC 5까지 (STORY 24개) — 여기까지 하면 원문 입력부터 규칙 적용, 두 AI 번역·교차검토, 최종 번역 표시까지 처음부터 끝까지 한 번 동작합니다.

> EPIC은 집 짓기의 골조·전기 공사처럼 큰 작업 묶음이고, STORY는 버튼 하나나 화면 변화 하나처럼 한 번에 만들고 눈으로 확인할 수 있는 작업입니다.

## 범위와 진행 원칙

- FRD의 필수 기능 54개를 모두 계획에 포함한다.
- 로컬에서 작동하는 EPIC 11까지가 필수이며 EPIC 12 배포만 선택이다.
- 개발 순서는 데이터 구조 → 화면 → 규칙·AI 연결 → 관리 기능 → 기록·안전 → 전체 점검 순서다.
- 개발·자동 테스트에서는 가짜 회사명·가짜 인명·가짜 메시지만 사용한다.
- STORY가 많을수록 AI 사용량도 늘어나므로 한 번에 2~3개씩 진행해도 된다.
