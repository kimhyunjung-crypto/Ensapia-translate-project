# ENSAPIA Slack 비즈니스 메시지 AI 번역 워크벤치 디자인 제안

상태: 완료

- 기준 문서: `docs/prd.md` v1.0
- 시안 미리보기: `design/preview/index.html`
- 확정 디자인: A · Focus White
- 주 사용 기기: PC 우선, 모바일은 반응형으로 대응
- 확정일: 2026-09-01

## 1. 디자인 목표

ENSAPIA Seoul 구성원이 Slack 메시지를 붙여 넣고 최종 번역을 빠르게 복사할 수 있는 경량 웹 워크벤치를 만든다. 프로그램의 사전 규칙 적용과 내부의 ChatGPT·Gemini 번역 및 교차검증 과정은 화면에 노출하지 않고, 사용자는 원문 입력과 하나의 최종 결과에만 집중하도록 한다.

## 2. 공통 브랜드·UI 기준

- 브랜드 기본색: `#2951DA`
- 보조 배경색: `#EDF2FF`, `#F7F9FC`, `#FFFFFF`
- 본문색: `#172033`
- 보조 본문색: `#677084`
- 기본 경계선: `#E5E9F1`
- 기본 간격 체계: 8px 단위
- 기본 모서리: 12~16px, Airy Canvas는 20~24px
- 글꼴: 한국어·일본어 가독성이 좋은 시스템 산세리프 스택
- 로고: 제공된 ENSAPIA 워드마크의 비율과 색상을 유지하고 상단에 배치한다. 재도색·변형하지 않는다.
- 접근성: 핵심 텍스트와 버튼은 충분한 색 대비를 유지하며 상태를 색상만으로 구분하지 않는다.

## 3. 확정 디자인과 검토 시안

### A. Focus White — 구현 기준으로 확정

- 무드: 신뢰감 있고 절제된 업무 도구
- 로고: 좌측 상단
- 구조: 상단 내비게이션, PC에서는 원문과 최종 번역을 좌우 배치
- 브랜드색 사용: 번역 실행, 활성 메뉴, 핵심 상태에만 제한적으로 사용
- 장점: 번역 입력과 결과 비교가 가장 빠르고 장시간 사용 시 피로가 적다.

### B. Blue Frame

검토용 대안이며 실제 구현 기준에서는 제외한다.

- 무드: ENSAPIA 브랜드 시스템이 강하게 느껴지는 사내 운영 도구
- 로고: 흰색 영역의 좌측 상단
- 구조: `#2951DA` 세로 내비게이션과 우측 작업 영역
- 브랜드색 사용: 내비게이션 프레임에 넓게 사용
- 장점: 향후 관리 기능과 사용자가 늘어날 때 화면 체계가 명확하다.

### C. Airy Canvas

검토용 대안이며 실제 구현 기준에서는 제외한다.

- 무드: 가볍고 현대적인 AI 작업 공간
- 로고: 우측 상단
- 구조: 옅은 블루 그라데이션 위에 원문과 결과 카드를 세로 배치
- 브랜드색 사용: 버튼, 포커스, 은은한 배경 광원에 사용
- 장점: 여백이 넓고 모바일에서도 자연스럽게 이어진다.

## 4. 화면별 설계

PRD의 화면 4개를 세 시안 모두에서 확인할 수 있다. 미리보기의 화면 메뉴로 전환한다.

### 4.1 번역 워크벤치

- 원문 입력창과 자동 감지 언어 표시
- 번역 실행 전 프로그램이 인명·호칭·회사 용어·말투 규칙을 찾아 고정하지만 별도 단계나 중간 결과는 화면에 노출하지 않음
- 실행 중에는 하나의 통합 진행 상태만 노출
- 최종 번역본 하나와 복사 버튼 제공
- 모델별 결과와 교차검증 내용은 사용자 화면에서 숨김
- 일부 모델 호출이나 저장이 실패하면 통합 오류 안내와 `다시 시도` 버튼 표시

### 4.2 용어집 관리

- 용어 검색, 언어 방향 필터, 활성 상태 확인
- 원어, 권장 번역, 설명, 상태 중심의 표 구조
- `+ 새 용어` 선택 시 모달 입력 폼 제공
- 입력 항목: 원어, 권장 표기, 원어 언어, 적용 방향, 설명, 사용하지 않을 표기, 활성 상태
- 필수값을 입력해 저장하면 미리보기 목록에 즉시 추가
- 각 행의 메뉴에서 수정·비활성화·다시 활성화
- 여러 용어를 한꺼번에 등록할 수 있는 파일 가져오기 제공

### 4.3 인명·직책 관리

- 여러 한국어 인식 표현과 하나의 일본어 통합 표기를 카드 형태로 확인
- 미리보기의 인명은 구조 설명을 위한 가상 예시
- `+ 새 멤버` 또는 추가 카드를 선택하면 모달 입력 폼 제공
- 기본 정보 입력은 제외하고 언어별 표기와 호칭만 입력
- 입력 항목: 복수의 한국어 인식 표현, 일본어 통합 표기, 역방향 번역용 한국어 통합 표기, 활성 상태
- 한국어 인식 표현은 Enter 또는 쉼표로 추가하는 태그 방식이며 중복 표현은 자동으로 제외
- 예: `이시와타리 대표님`, `이시와타리상`, `이시와타리님`을 모두 `石渡さん`으로 통합
- 역방향 예: `石渡さん`을 `이시와타리님`으로 통합
- 입력 중 각 한국어 표현이 어떤 일본어 표기로 변환되는지 실시간 미리보기 제공
- 필수값을 입력해 저장하면 미리보기 카드 목록에 즉시 추가
- 각 카드의 메뉴에서 수정·비활성화·다시 활성화

### 4.4 운영 설정

- 모델 운영 모드, 예상 비용 상태, 저장 정책을 한 화면에서 확인
- 원문·모델별 결과·교차검증 결과·최종 번역본 저장 원칙을 명시
- 인사·요청·거절·사과·독촉·확인·감사 등의 문체 규칙 등록·수정·비활성화
- 번역 건별·일별·월별 사용량과 예상 비용, 비용 상한 경고 확인
- 기간을 선택해 저장된 번역 데이터 일괄 삭제

## 5. 반응형 기준

- PC 화면을 우선 설계하고 미리보기 상단의 `PC` 버튼 상태를 구현 기준으로 사용한다.
- 모바일은 반응형 보조 범위로 대응하며 내비게이션을 압축하고 입력과 결과를 세로로 쌓는다.
- 모바일 전용 앱이나 모바일만을 위한 별도 기능은 만들지 않는다.

## 6. 인터랙션 기준

- 디자인 A/B/C 전환
- 번역, 용어집, 인명·직책, 설정 화면 전환
- PC/모바일 미리보기 전환
- 번역 실행 시 단일 로딩 상태 후 최종 번역 표시
- 사전 규칙 적용, 모델별 번역, 교차검토와 최종 종합은 모두 단일 로딩 상태 안에서 처리
- 최종 번역 복사 및 복사 완료 피드백
- 새 용어·새 멤버 입력 모달 열기, 취소, 배경/ESC 닫기, 필수값 검증, 저장 완료 피드백
- 용어·인명·문체 규칙 수정, 비활성화, 다시 활성화
- 번역 실패 안내와 다시 시도
- 비용 상한 도달 전 확인, 저장 데이터 기간별 일괄 삭제 확인
